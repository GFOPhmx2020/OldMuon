# muon_stalactite_full 实现方案（待确认）

- 独立 C++ Geant4 程序 muon_stalactite_full.cc，配套 CMake 与 ROOT 绘图；默认 100000 个初级 μ 子事例，固定可配置随机种子。
- 默认 Halite，圆柱半径 10 m、长度 200 m，中心位于原点；材料组成与密度读取项目 mineral_library.yaml 或由配套工具转换，保留其它材料调用入口。
- GT 使用用户给定三个分段表达式，包括第三段幂律项的有效能量替换。建议 gamma=2.7，E 为动能 GeV，范围 0.1–10000 GeV，天顶角 0–90 度，方位角均匀。这些范围与能量定义需要确认并写入输出元数据。
- 只模拟穿过圆柱顶面的入射；顶面面积均匀抽样，联合分布正比 GT(E,theta)*cos(theta)*sin(theta)，不得分别独立抽取能量和天顶角。侧面入射不计。建议 μ+/μ−=1.3（配置参数，不由 GT 公式决定）。
- 联合分布采用可检查收敛的二维数值 CDF 抽样，明确网格近似，记录积分通量与采样范围；抽样自检独立于昂贵输运。
- Geant4 输运保留全部后代级联；对每条次级核轨迹在出生时记录一次事件号、track/parent ID、Z/A、生成过程、动能、xyz。默认 1 keV 记录阈值，仅过滤输出，不杀死低能粒子。将核反应产物与弹性反冲通过生成过程区分，避免把所有离子统称弹性反冲。
- 按元素生成 X-Z 原始计数与投影面密度图；保存全部核明细。面积密度 N/(m²)，不误称体积密度。
- 从每个材料 Range/DEDX_Z{Z}_A{A}.txt 的第四列读取射程，um 转 nm；插值得到出生能量对应的 CSDA 射程，并明确它不是逐步累计路径或可观测损伤径迹。缺表或越界单独计数，不静默外推。
- z–射程–N 三维图用 ROOT TH2 + SURF2，第三轴为每个二维 bin 的核数量；按元素输出，并保存 ROOT/PNG/PDF。另存深度 d=L/2-z。
- 提供充分中文模块注释、构建运行说明、参数与单位说明；检查采样边界、归一化、核去重、表插值、计数守恒。仅在依赖可用时报告编译/运行通过，不把代码检查当作十万事件实际模拟。
